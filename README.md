# MoneyMate 

MoneyMate is a full-stack personal finance tracker that helps users manage
their income and expenses while providing financial analytics through a
clean and responsive interface.

##  Features

- User Registration and Login
- JWT-based Authentication
- Add and manage expenses
- Add and manage income
- Dashboard with income, expense, and balance summary
- Category-wise financial analytics
- Monthly financial analytics
- Protected routes
- Responsive user interface

##  Tech Stack

### Frontend
- React.js
- Vite
- React Router
- Axios
- Tailwind CSS

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcryptjs
